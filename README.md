# ARCHIVO 47

## Plataforma web interactiva para investigación de casos ficticios

ARCHIVO 47 es una plataforma web en la que los usuarios reciben
casos ficticios de investigación y deben analizar diferentes fuentes
de información para construir una teoría y resolver cada expediente.

## Funcionalidades principales

- Registro e inicio de sesión
- Gestión de usuarios
- Consulta de casos
- Investigación de expedientes
- Sospechosos
- Evidencias
- Documentos
- Mensajes
- Llamadas
- Ubicaciones
- Línea temporal
- Pistas
- Acertijos
- Presentación de teorías
- Resultados
- Logros

## Tecnologías

- Java
- Spring Boot
- HTML5
- CSS3
- JavaScript
- MySQL
- JPA / Hibernate
- Git / GitHub

## Arquitectura

El sistema utiliza una arquitectura de tres capas:

1. Capa de presentación
2. Capa de lógica de negocio
3. Capa de acceso a datos
